# 桌面客户端（exe）—— 员工下载安装即用

## 一、员工怎么用

### 下载（员工自己操作）

用**电脑**打开这个地址（要连店里的 WiFi）：

```
http://192.168.1.161:3001/download
```

页面上有「下载安装包」按钮，点了就能下载（约 106MB）。

### 安装

1. 双击下载好的 `尚品居经营系统-安装版-1.0.0.exe`
2. 一路「下一步」（可以改安装目录，也可以默认）
3. 装完桌面会出现「尚品居经营系统」图标

### 使用

双击桌面图标 → 用店长给的账号密码登录。

> 客户端只是个壳，数据都在服务器上。所以使用时需要：
> - 电脑连着店里的 WiFi
> - 店长那台服务器电脑开着

## 二、连不上服务器怎么办

客户端打不开时会自动显示引导页，列出三个常见原因：

1. 这台电脑没连店里的 WiFi
2. 店长那台服务器电脑没开机
3. 服务器地址变了（路由器换了 IP）

**如果是第 3 种**：在引导页的输入框里填新地址（问店长要），点「保存并重新连接」就行。地址存在本机，**不用重新下载安装包**。

也可以先点「测试连接」确认地址对不对。

## 三、店长须知

### 客户端默认连的地址

`http://192.168.1.161:5173`

写死在 `desktop/main.cjs` 的 `DEFAULT_SERVER`。如果本机 IP 永久变了（路由器没做 MAC 绑定），要改这里重新打包；**做了 MAC 绑定就不用管**。

### 重新打包（更新客户端后）

```bash
# 1. 先清掉上次打包的残留（关键！否则会被删除保护拦截）
cd artifacts/desktop
mv win-unpacked _old-win-unpacked-$(date +%s)
mv win-unpacked.tmp _old-tmp-$(date +%s)   # 如果有

# 2. 打包
cd ../..
npm run desktop:dist
```

产物：`artifacts/desktop/尚品居经营系统-安装版-<版本>.exe`

> ⚠️ 最后一步清理临时卸载程序时，环境的删除保护会报错，
> **但安装包已经生成好了**，忽略即可。

### 打包环境的三个坑（已修，别再踩）

| 问题 | 原因 | 已修方案 |
|---|---|---|
| `No JSON content found in output` | 没装 pnpm | `npm install -g pnpm@9` |
| `packages field missing or empty` | `pnpm-workspace.yaml` 缺 packages 字段 | 补上 `packages: - "."` |
| `safe-delete 操作失败`（图标转换） | icon.png 需联网下载转换工具 | 用 ImageMagick 生成 `build/icon.ico`，配置改用 ico |

生成图标的命令（如果以后要换图标）：

```bash
magick build/icon.png -define icon:auto-resize=256,128,64,48,32,16 build/icon.ico
```

### 校验打包内容

```bash
node scripts/verify-desktop-build.mjs
```

会列出 asar 内的文件，确认 `desktop/main.cjs`、`preload.cjs`、`offline.html` 都在。

### 下载页的工作原理

- `GET /download` —— 中文下载页（免登录，服务器直接返回 HTML）
- `GET /download/file` —— 流式返回 `artifacts/desktop` 下**最新的** `.exe`

所以重新打包后，**不用改任何代码**，员工刷新下载页拿到的就是新版。

## 四、已知优化点

- asar 里仍打包了 `node_modules` 和 `dist`（约 59MB），其实客户端不需要（它只加载远程页面）。
  精简 `package.json` 的 `files` 配置能显著减小安装包，后续可做。
- Windows 会提示"未知发布者"（没有代码签名证书）。员工点「更多信息 → 仍要运行」即可。
  要去掉这个提示需要买代码签名证书（每年几百到几千元）。
