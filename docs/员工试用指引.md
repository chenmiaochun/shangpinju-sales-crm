## 四、遇到问题，点右下角「记一笔」

任何页面右下角都有一个**「记一笔」**按钮。用着不顺手、想要什么功能、哪里报错了，点它写一句就行，会自动记下来。

提交时选一下属于哪块（订单报价 / 产品主数据 / 客户线索 / 库存 / 经营分析 / 系统其它）。

**写得越具体越好**，比如：
- ❌ 「不好用」
- ✅ 「开单时选客户要翻很久，希望能按手机号搜」

老板能看到所有想法，定期整理后安排改。

## 五、打不开怎么办

先自己排查三步：

1. **WiFi 连的是店里的吗？** 换成店里的 WiFi 再试
2. **地址输对了吗？** 是 `192.168.110.127:5173`，注意中间是点、最后是冒号 5173
3. **老板电脑开了吗？** 系统跑在老板电脑上，他关机了大家就都打不开

三步都试过还是不行，告诉老板。

## 六、给老板的注意事项

1. **服务跑在你这台电脑上**，电脑关机或断网，员工就都访问不了。所以营业时间尽量别关机。
2. **服务已经设了开机自启 + 崩溃自愈**：重启电脑后会自动起来，中途挂了 30 秒内自动恢复，不用手动管。
3. **⚠️ 不要在服务运行时，用别的工具直接改数据库文件**（比如用脚本打开 `sales.sqlite` 写数据）。SQLite 在 WAL 模式下，外部进程一改，服务持有的连接就会变成只读，所有登录都会 500。要改数据就停服务再改，或者走系统里的功能。
4. **每天 21:30 自动备份**，存在 `backups/` 目录，保留最近 7 天。
5. 常用命令（在项目目录 `C:\Users\Administrator\Documents\销售软件` 下执行）：
   ```
   node scripts/install-autostart.mjs status   看服务状态
   node scripts/network-selfcheck.mjs          网络自检
   node scripts/backup-daily.mjs run           立刻备份一次
   ```
6. 需求池在 `docs/BACKLOG-需求池.md`，员工提的想法会汇总到这里。
