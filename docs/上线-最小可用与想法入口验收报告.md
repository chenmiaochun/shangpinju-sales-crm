## 一、这次做了什么

### 1. 开机自启 + 崩溃自愈（原来最大的坑）

新增 `scripts/service-guard.mjs` + `scripts/install-autostart.mjs`：

- 注册 Windows 计划任务 `ShangPinJuSalesGuard`，**每次登录自动拉起服务**
- 守护进程每 30 秒检查 3001（后端）、5173（前端），**任一不通就自动重启**
- 刚拉起给 60 秒宽限，避免 vite 还没编译完被误判
- 端口本来就通时不重复启动（手动 `npm run dev` 也不会被抢）
- 计划任务用系统 node（`C:\Program Files\nodejs\node.exe`），不依赖 WorkBuddy 的托管运行时

**实测**：手动杀掉服务进程后，**3 秒内自动恢复**（后端 + 前端都起来，日志可查）。

日志位置：`logs/service-guard-YYYY-MM-DD.log`

### 2. 每日闭店自动备份

新增 `scripts/backup-daily.mjs`：

- 计划任务 `ShangPinJuSalesBackup`，每天 **21:30** 自动跑
- 备份 `sales.sqlite`、`app.db`、`uploads/`（328 个附件）
- 用 SQLite 的 `VACUUM INTO` 产出一致快照，**不用停服务**，也不会漏掉 WAL 里没合并的数据
- 保留最近 7 天 + 最近 8 个周日的归档（uploads 一次 358 MB，全留会把硬盘吃光）

**实测**：备份成功，已验证可打开（7 张表、512 条审计、328 个附件）。
