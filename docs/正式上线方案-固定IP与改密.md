## 一、本次完成

### 1. 固定 IP（避免路由器 DHCP 重启后 IP 漂移）

- **本机静态 IP 已设置**：网卡 `WLAN 3`（Realtek RTL8192FU USB 无线网卡）从 DHCP 改为静态
  - IP：`192.168.1.161`
  - 子网掩码：`255.255.255.0`
  - 网关 / DNS：`192.168.1.1`
- 验证：外网（baidu 200）、本机（3001/5173 200）、局域网（192.168.1.161:5173 200）均正常
- 员工访问地址（永久）：`http://192.168.1.161:5173`

> ⚠️ **当前上网用的是 USB 无线网卡（Realtek RTL8192FU）**，如果该 USB 网卡被拔下/换 USB 口/换设备，Windows 可能会把它识别成新网卡，本机静态 IP 配置会失效。
> 因此**强烈建议在路由器里做 MAC 绑定**（见下），做双保险。

### 2. 员工自助修改密码（commit 68f86f5）

**问题**：系统原有流程只有"店长重置员工密码"，员工自己改不了密码。UI 文案说"员工登录后须修改密码"但实际没入口。

**新功能**：
- 后端 `POST /api/auth/change-password`（需登录、校验当前密码、改完踢掉其他设备会话）
- 前端：右上角账号菜单 →「🔑 修改密码」→ 弹窗
- 规则：新密码 6 位数字 或 ≥10 字符，且不能与旧密码相同
- 改完本设备保持登录，手机/电脑等其他设备会被踢

**用法**：员工首次登录看到「须修改密码」提示 → 点账号菜单 → 修改密码 → 改成自己记得住的 → 完成。

## 二、老板要做的（路由器绑定双保险）

打开浏览器访问 `http://192.168.1.1`（路由器管理页），找「DHCP 服务器 / 静态地址分配 / IP 与 MAC 绑定」一类的菜单，添加：

| 字段 | 值 |
|---|---|
| MAC 地址 | `00-5C-C2-E3-89-B5` |
| IP 地址 | `192.168.1.161` |
| 备注 | 销售系统-本机 |

（Realtek RTL8192FU USB 网卡，物理地址见 ipconfig /all 验证）

不同品牌路由器位置不一样：
- TP-Link：高级设置 → 网络参数 → DHCP 服务器 → 静态地址分配
- 小米：常用设置 → LAN 设置 → 静态 IP 分配
- 华硕：LAN → DHCP 服务器 → 手动分配

**加完保存即生效**。之后无论本机 DHCP 租约怎么变、路由器重启多少次，`.161` 都属于这台电脑。
