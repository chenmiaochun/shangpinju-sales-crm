# 路由器固定 IP 操作指引

> 目的：让 `http://192.168.1.17:5173` 这个地址**永不失效**，员工收藏一次就能一直用。
>
> 做一次就行，5 分钟。

---

## 零、先说一件更要紧的事：建议改成网线

查下来你的电脑是走 **WiFi（WLAN）** 连路由器的：

| 项目 | 值 |
| --- | --- |
| 连接方式 | **WLAN（无线）** |
| 当前 IP | `192.168.1.17` |
| MAC 地址 | `8C-78-D7-E3-64-89` |
| 子网掩码 | `255.255.255.0` |

服务器走 WiFi 有三个隐患：

1. **WiFi 省电策略**会间歇性断流，员工端会偶发连不上；
2. 系统休眠/锁屏可能断开 WiFi，守护进程虽然在，但员工就是访问不到；
3. 信号波动会导致响应变慢，用起来像"系统卡"。

**建议：拿一根网线把这台电脑直接插到路由器上。** 插上后按下面的步骤重新查一次 IP 和 MAC（有线网卡的 MAC 和无线是不一样的），再做绑定。

如果实在不能走网线，那至少：
- 电源设置里把 WiFi 的"允许关闭此设备以节约电源"关掉；
- 电源计划设为"从不睡眠"。

---

## 一、先查你的路由器管理地址

在本机按 `Win + R`，输入 `cmd` 回车，执行：

```
ipconfig
```

找到正在用的那个网卡，看**「默认网关」**那一行，例如 `192.168.1.1` —— 这就是路由器地址。

---

## 二、登录路由器后台

浏览器打开网关地址（如 `http://192.168.1.1`），用路由器背面贴纸上的账号密码登录。

---

## 三、做 IP 与 MAC 绑定

不同品牌叫法不一样，找下面任意一个入口：

- **TP-Link / 水星 / 迅捷**：`DHCP 服务器` → `静态地址分配` / `地址保留`
- **小米 / Redmi**：`局域网设置` → `静态 IP 分配`（部分型号在"高级设置"里）
- **华为 / 荣耀**：`更多功能` → `网络设置` → `局域网` → `静态 IP`
- **华硕**：`LAN` → `DHCP 服务器` → `手动指定 IP`
- **H3C / 爱快 / 企业级**：`网络设置` → `DHCP` → `静态绑定`
- **没有这个功能的路由器**：看第六节的备用方案

填写内容：

| 字段 | 填什么 |
| --- | --- |
| MAC 地址 | `8C-78-D7-E3-64-89`（改成网线后要重新查） |
| IP 地址 | `192.168.1.17` |
| 备注/名称 | 尚品居销售服务器 |

保存后，**重启一次路由器**让规则生效（部分品牌需要）。

---

## 四、验证

1. 重启路由器后，在本机 `cmd` 里执行 `ipconfig`，确认 IP 还是 `192.168.1.17`；
2. 手机连同一个 WiFi，浏览器打开 `http://192.168.1.17:5173`，能出登录页就算成功；
3. 在本机命令行执行 `network-check.bat`（项目根目录有），它会把可访问的地址一次性列出来。

---

## 五、这跟开机自启是什么关系

两件事互补，都要做：

| 措施 | 解决什么 |
| --- | --- |
| **开机自启 + 守护进程** | 服务挂了/电脑重启了，自动拉起来 |
| **路由器固定 IP** | 员工收藏的地址不失效 |

只做自启不固定 IP：服务在跑，但地址可能变，员工打不开。
只固定 IP 不做自启：地址不变，但电脑一重启服务就没了。

---

## 六、备用方案（路由器不支持静态分配时）

**方案 A（推荐）**：在服务器上设静态 IP
控制面板 → 网络和共享中心 → 更改适配器设置 → 右键网卡 → 属性 → Internet 协议版本 4 → 使用下面的 IP 地址：

```
IP 地址：192.168.1.17
子网掩码：255.255.255.0
默认网关：<你的网关>
DNS：     <你的网关> 或 114.114.114.114
```

注意：这个 IP 要避开路由器的 DHCP 分配池（一般池子是 `.100`~`.199`，`.127` 可能冲突），建议改用池子外的地址如 `192.168.1.20`，但要同步告诉员工新地址。

**方案 B**：不改任何配置，靠系统现有的"换 IP 自动放行"兜底 —— 服务端不会报 403，但员工收藏的**旧地址会失效**，需要重新发地址。能用，但不省心。

---

## 七、做完后

把员工访问地址固定为：

```
http://192.168.1.17:5173
```

让员工在手机/电脑浏览器收藏这个地址即可（手机可以加到主屏幕，用起来像 App）。
