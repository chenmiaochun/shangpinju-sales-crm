## 一、做了什么

把飞书产品库（175 个整品）**一键批量搬进系统**的导入工具，挂在「产品主数据」页右上角。

**导入规则**（按老板确认的三个默认值 + 已定稿列映射）：

| 飞书字段 | 系统目标 | 说明 |
|---|---|---|
| 品类 | `ProductCategory` | 已有同名品类 → 复用；没有 → 新建（如「沙发」「餐桌」） |
| 基型编号（如 SH-RQ-002） | 主件代码 | 沿用原编号，不重新生成 |
| 产品编号（如 SH-RQ-002-R2） | `SkuUnit.sku` | 一比一：1 整品 = 1 主件 + 1 SKU |
| 产品名称 | 主件名称 + SKU 名称 | — |
| 尺寸(MM) / 材质 | `specValues`（尺寸、材质） | — |
| 吊牌价 | `SkuUnit.price`（成品价） | 内部参考价飞书全空 → 成本留空，毛利分析标「无成本数据」 |
| 产品状态 | 过滤条件 | 仅导「在售」；非在售自动跳过 |
| 供应方式（飞书全空） | `supplyType: '现货'` | 默认值 |
| 库存（飞书无） | `availableStock: 0` | 默认值，导入后到货/手工台账补 |
| — | `listed: true` 上架 | 导入即上架，开单页立即可选 |

**内置防护**：
- 列名容错：表头支持「产品名称 / 名称」等别名，不因列名差异失败
- SKU 查重：已存在的产品编号跳过（幂等，重复导入不产生脏数据）
- 跳过清单：非在售状态；SH-RQ-002-R2（备注“删除此产品，重复”）
- 逐行收集错误：哪行错、错在哪，导入前完整预览，不会静默半成功
- 支持 .xlsx / .csv；带「下载模板」按钮（表头 + 示例行 + 默认值说明）

**交互流程**：点「批量导入」→ 上传文件 → 自动解析 → 预览（新建品类 N 个 / 主件 N 个 / SKU N 个 / 跳过 N 条 / 错误 N 条，错误逐行列出）→ 点「确认导入」→ 一次性合并写入并落盘。

## 二、验收操作路径（老板自测）

1. 登录 `localhost:5173`（admin / AcceptTest-2026）→ 左侧「产品主数据」
2. 右上角点 **「批量导入」** → 对话框内点 **「下载模板」**，按模板填 2~3 行真实产品数据（或直接导出飞书 Excel 改表头）
3. 上传文件 → 看预览数字（新建品类/主件/SKU/跳过/错误）是否符合预期
4. 点「确认导入」→ 关掉对话框
5. 切到「品类与主件」页签：新品类 + 主件应出现；切到「库存台账」页签：新 SKU 应出现（库存 0、上架、现货）
6. 打开「销售开单」→ 顶部来源切到「产品库」→ 新导入的产品应可直接选规格加入
7. 错误验证（可选）：把某行产品编号改成已在系统里的编号再导一次 → 预览应显示「跳过：编号已存在」，且不产生重复
